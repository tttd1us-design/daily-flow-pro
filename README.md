# 🚀 Daily Flow Pro - 1% Life OS (Executive Command Center)

> **인생을 바꾸는 1% 실행력 & 지식 아카이브 올인원 라이프 OS**
> Google Gemini AI 1% 팩트 코칭, 딥 포커스 젠 모드(Zen Mode), 무제한 IndexedDB 저장소, 미완료 과업 자동 이월(Rollover), 주제별 지식 위키(Knowledge Hub) 탑재

---

## 🌟 주요 핵심 기능

1. **⚡ 딥 포커스 몰입 젠 모드 (Deep Focus Zen Mode)**
   - 주변의 모든 시각적 노이즈를 차단하고, 화면 전체에 **오늘의 북극성 미션 1개 + 뽀모도로 타이머 + 체크리스트**만 띄워주는 극강의 몰입 환경.

2. **🧠 Gemini 1% 엘리트 라이프 코칭 센터 (3대 페르소나)**
   - ⚡ **냉철한 팩트 폭격기**: 핑계와 미루기를 타파하고 5분 즉시 실행 강제.
   - 🧠 **전략적 비즈니스 멘토**: 80/20 법칙과 데이터 기반 레버리지 목표 분해.
   - 🌿 **마인드셋 & 멘탈 회복**: 번아웃 케어 및 심리적 회복 루틴.
   - 대화 답변에서 도출된 조언을 **원클릭 클립보드 복사** 및 **대시보드 To-Do/One Thing에 실시간 자동 연동**.

3. **🚨 미완료 과업 1초 자동 이월 (Smart Task Rollover)**
   - 어제 끝마치지 못한 To-Do가 과거로 증발하지 않고, 오늘 대시보드로 원클릭 자동 이월되어 100% 폐루프 실행 보장.

4. **📚 주제별 지식 위키 & 학습 아카이브 (Knowledge Hub)**
   - 날짜별 기록을 넘어 주제/카테고리별로 지식이 자동 분류되고 축적.
   - 강의 도표, 필기 사진 등 **학습 이미지 갤러리 무제한 첨부**.
   - **노트 전체 1초 클립보드 복사** 및 **Gemini 지식 심화 분석 & 복습 퀴즈 생성**.

5. **🛡️ 용량 무제한 `IndexedDB` 비동기 스토리지 엔진**
   - 브라우저 로컬 저장 한계(5MB)를 극복하여 대용량 이미지와 데이터를 안전하게 영구 보관.
   - 단일 JSON 파일로 언제든 **전체 데이터 백업 및 100% 안전 복원** 지원.

## 🖥️ 기술 스택 (Tech Stack)
- **Frontend**: Vanilla HTML5, CSS3 (Modern Glassmorphism & Responsive Layout), JavaScript (ES6+ Native Bundle)
- **Storage Engine**: Browser Native `IndexedDB` API + LocalStorage Safe Fallback
- **AI Integration**: Google Gemini 1.5 Flash / 1.5 Pro REST API
- **Typography & Icons**: Pretendard, Nanum Myeongjo, JetBrains Mono, Font Awesome 6

## 🚀 빠른 시작 (Quick Start)
별도의 빌드나 서버 설치 없이 `index.html` 파일을 브라우저로 열기만 하면 즉시 모든 기능이 동작합니다.

```bash
# 저장소 복제
git clone https://github.com/tttd1us-design/daily-flow-pro.git

# 실행 (Windows PowerShell)
Start-Process index.html
```
