# 📁 Daily Flow Pro - 전용 데이터베이스 보관소 (Database Hub)

이 폴더는 Daily Flow Pro Life OS에서 작성된 모든 성장 데이터가 파일 단위로 체계적으로 분리되어 안전하게 영구 보관되는 데이터베이스 폴더입니다.

---

## 📂 폴더 구조 안내

```
database/
├── data_state.json          # 전체 시스템 통합 데이터베이스 (목표, To-Do, 설정 등)
├── goals.json               # 인생 5대 핵심 영역 목표 로드맵 DB
├── principles.json          # 나만의 인생 원칙 & 의사결정 규칙 DB
├── journals/                # 날짜별 마크다운(MD) 일기 & 회고 원문 보관소
│   └── 2026-08-17.md
└── studies/                 # 날짜/주제별 학습 메모 & 지식 노트 보관소
    └── 2026-08-17_데이터분석.md
```
